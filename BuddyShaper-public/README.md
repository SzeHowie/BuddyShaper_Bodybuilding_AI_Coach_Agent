# BuddyShaper (public share)

Chat coach demo with **Gymergee（俊美雞）**. Runs fully in the browser — **no API keys**, no backend, no personal accounts.

## Run locally

1. Install [Node.js LTS](https://nodejs.org/)
2. In this folder:

```bash
npm install
npm run dev
```

3. Open the URL Vite prints (usually http://localhost:5173/).

## What is included

- Goal-matched recipes and macros
- Lift-form tips from a short clip upload
- Plate calorie estimates from a photo (local demo matcher, not a cloud vision API)

Estimates are coaching aids, not medical advice.
